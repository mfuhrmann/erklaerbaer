# Regelwerke

Hier liegen die Spielanleitungen – im Repository leer, weil Regelhefte
urheberrechtlich geschützt sind. Eigene PDFs am einfachsten über die Webseite
importieren („➕ Anleitung importieren“) oder von Hand, siehe README im
Hauptordner („Neues Spiel hinzufügen“).

Pro Spiel entstehen hier:

| Datei | Inhalt |
|---|---|
| `<id>.pdf` | Regelheft (ggf. mit unsichtbar eingetragenen Symbolnamen) |
| `<id>.orig.pdf` | hochgeladenes Original |
| `<id>.md` | bereinigter Text, den das Modell liest |
| `<id>.roh.md` | Rohausgabe der Umwandlung (ältere Spiele: `<id>.docling.md`) |
| `<id>.symbole.json` | Namen der Bildsymbole aus der Galerie |
| `<id>.einleitung.txt` | „Worum geht's?“: thematische Einleitung aus dem Regelheft |
| `.papierkorb/` | entfernte Spiele („🗑️ Spiel entfernen“), zum Zurückholen |
| `spiele.json` | Anzeigenamen aller Spiele |
